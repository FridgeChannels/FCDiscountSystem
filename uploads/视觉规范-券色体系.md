# 视觉规范 · 优惠券分等级色彩体系（跨品牌通用）

本规范定义一套**与折扣等级绑定、可跨品牌复用**的优惠券配色体系。
目标：同一套交互/版式结构，换主题即可适配不同品类品牌；同一品牌内，
折扣力度越高，券色越「稀有 / 越像中奖」，形成清晰的等级递进感。

---

## 一、设计原则

1. **等级即颜色**：颜色只表达「折扣等级」，不表达品牌色。等级 0=最低折扣，5=最高折扣。
2. **稀有度递进**：从低到高，明度/饱和度/特殊工艺（金属、渐变）逐级强化，最高级用「黑金 / 双色渐变」收口，制造稀缺感。
3. **主色 + 辅助色成对出现**：主色用于券面/背景，辅助色用于描边、徽标、数字高光、CTA 点缀。
4. **前景色（ink）独立定义**：每级预设一个已校验对比度的推荐前景色，浅底用深字、深底用浅字，禁止前景色随主色自由取值。
5. **一品牌一主题**：单个品牌全程只用一套主题，不混用 DTC 与快消两套。

---

## 二、等级映射

| data-tier | 等级    | 含义               |
| --------- | ----- | ---------------- |
| `0`       | 最低级 OFF | 入门 / 小奖励         |
| `1`       | 一级 OFF | 轻会员感             |
| `2`       | 二级 OFF | 开始有吸引力           |
| `3`       | 三级 OFF | 明显优惠             |
| `4`       | 四级 OFF | 稀有、高价值           |
| `5`       | 最高级 OFF | 顶级奖励 / 大奖        |

> 等级对应「折扣力度的相对档位」，不是折扣绝对数值。
> 例如某品牌阶梯 15%→20%→25%，可分别落到 tier 1 / 2 / 3，由运营按稀有度分配。

## 三、主题 A · 高级 DTC 版

**适用品类**：美妆、护肤、香氛、服饰、家居
**气质**：金属感、克制、随等级升高愈发稀有

| 等级    | 主色            | 辅助色           | 推荐前景 ink | 感觉        |
| ------- | ------------- | ------------- | --------- | --------- |
| 最低级 OFF  | 奶油金 `#F6E7C8` | 浅棕 `#A8783B`  | `#6E4E23` | 小奖励       |
| 1级 OFF | 香槟金 `#EFD39A` | 古铜金 `#9B6A2E` | `#6B4A1F` | 轻会员感      |
| 2级 OFF | 蜜桃金 `#F6B98E` | 焦糖棕 `#8A4E2A` | `#7A3F1E` | 温暖、开始有吸引力 |
| 3级 OFF | 玫瑰金 `#D98B7D` | 深玫瑰 `#7C3A35` | `#4E211D` | 明显优惠      |
| 4级 OFF | 酒红金 `#8E2F3C` | 香槟金 `#F7DFA3` | `#F7E9C8` | 稀有、高价值    |
| 最高级 OFF | 黑金 `#211A16`  | 金色 `#D8A84F`  | `#D8A84F` | 顶级奖励      |

**特殊处理**
- 4 级（酒红金）：深底 + 浅金字 + 香槟金描边，营造高价值感。
- 最高级（黑金）：券面用黑金深色渐变 `#2c241d → #211A16 → #14100d`，金色描边与数字，呈现稀缺。

**适用品类**：零食、饮料、快消
**气质**：明快、跳色、越高级越像「中大奖」

| 1级 OFF | 薄荷绿 `#BDEFD8`            | 绿色 `#1EA66A`  | `#0E6B43` | 清新  |
| 2级 OFF | 天空蓝 `#BFE4FF`            | 蓝色 `#318AD8`  | `#1C5C92` | 明亮  |
| 3级 OFF | 珊瑚橙 `#FF8A65`            | 橘红 `#E94F37`  | `#6E2410` | 兴奋  |

## 五、落地（CSS token）

配套实现见 `fc-tiers.css`，已在 `src/main.jsx` 引入。它是**纯变量层**，不直接改任何元素外观，按需消费。

### 5.1 选主题 + 选等级

```html
<div data-coupon-theme="dtc">        <!-- dtc | pop -->
  <div class="coupon" data-tier="2"> <!-- 0 ~ 5 -->
    ...
  </div>
</div>
```

### 5.2 消费 token

```css
.coupon {
  background:   var(--coupon-gradient); /* 主色推导出的券面渐变 */
  color:        var(--coupon-ink);      /* 推荐前景色 */
  border-color: var(--coupon-accent);   /* 辅助色：描边/徽标/高光 */
}
```

每个 `[data-tier]` 暴露的变量：

| 变量                  | 含义                         |
| ------------------- | -------------------------- |
| `--coupon-main`     | 主色                         |
| `--coupon-accent`   | 辅助色                        |
| `--coupon-ink`      | 推荐前景色（已配好深/浅）        |
| `--coupon-gradient` | 由主色推导的券面渐变（最高级单独定义）|

> 中间等级的渐变由主色经 `color-mix` 自动加深/提亮生成，无需手填；
> 两套主题的「最高级」单独覆盖为黑金 / 紫蓝渐变。

---

## 六、使用约束

- **不要**用辅助色当大面积背景；辅助色只做点缀（描边、徽标、数字、CTA）。
- **不要**自定义前景色，统一用 `--coupon-ink`，保证对比度与可读性。
- **不要**在同一品牌内混用两套主题。
- 新增品类时，**优先复用**最接近气质的主题；确需扩展再新增 `data-coupon-theme` 值，并补齐 0~5 全部等级的主色/辅助色/ink。
- 等级到具体折扣值的映射由运营配置，设计侧只保证「等级越高越稀有」的视觉递进成立。
